# Charity Management System

## Project Overview
The Charity Management System is a Python-based project designed to streamline the management of donors and donations for a charity organization. It provides an efficient way to handle donor information, track donations, and generate reports, ensuring transparency and ease of use.

## Features
- **Donor Management**: Add, update, and retrieve donor information, including name, email, and phone number.
- **Donation Tracking**: Record donations with details such as amount, type (cash or non-cash), and timestamp.
- **Authentication**: Secure donor accounts with username and password validation.
- **Reports**: Generate summaries of donations and donor activities.

## Project Structure
- **Charity Management System.py**: The main Python script containing the implementation of the system.
- **readme.md**: Documentation for the project.
- **Test Cases**: A separate document outlining test cases for the system.

## How to Use
1. Run the `Charity Management System.py` script.
2. Use the menu options to add donors, record donations, and view reports.
3. Follow the prompts to input required information.
